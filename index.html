如何运行 / 复现

在线可交互 Demo

打开 travelcontent-ai.app.workbuddy.host，输入任意城市即可实时生成脚本 + 脚本资源 + 补充资源。

本地工程（零模型依赖）

① git clone 仓库 → ② npm i @fly-ai/flyai-cli → ③ 填 FLYAI_API_KEY 到 .env → ④ python src/cli.py 开封 --days 2 --category 历史古迹

阿里云百炼 Managed Agent

装 alibaba-flyai/flyai-skill → 贴 prompts/system_prompt.md → 配 FLYAI_API_KEY → 直接对话产出行程 + 脚本。详见 agent/agent-config.md。

Node 交互服务

进入 demo-interactive/，npm install && node server.js，访问 http://localhost:3000 即可本地体验。
